## 🚀 Featured Project

### UART 8N1 Transmitter

A modular RTL implementation of a UART transmitter that sends 8-bit data with one start bit and one stop bit.

**Key Features**
- Modular RTL design with separate controller, shift register, and counter modules
- UART frame transmission with LSB-first data ordering
- Testbench-based functional verification
- Simulation waveform inspection and debugging
- Automated simulation testing with GitHub Actions
- Synthesis, timing analysis, and physical-design flow evaluation using Yosys and OpenLane

**Tools Used**

`Verilog/SystemVerilog` · `Icarus Verilog` · `GTKWave` · `Yosys` · `OpenLane` · `GitHub Actions`

🔗 **[View Repository →](https://github.com/anhtuancurrentlybusy/uart-8n1-tx)**
